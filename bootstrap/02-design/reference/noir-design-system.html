1. Design Philosophy

Noir est un instrument, pas une vitrine. L'interface s'efface pour laisser la musique au premier plan.

Principles

La musique d'abord
Album art is the only color. The UI stays monochrome to never compete with the artwork.
Depth through transparency
Glass morphism (backdrop-filter blur) creates hierarchy without color.
Intentional motion
Every animation communicates a state change. No decorative motion.
macOS-native
Context menus, glass effects, smooth easing. A first-class macOS citizen.

Identity

The Noir identity borrows from hi-fi: precision, noble materials, silent control.
100% monochrome UI (white, grays, black)
Green = playing state only
Red = errors and destructive actions only
No colored accents, gradients, or tinted backgrounds
No emoji, no decorative blobs, no colored shadows

Strict Rules

ALWAYS: Double backdrop-filter with -webkit-backdrop-filter (WebKit/Tauri)
ALWAYS: Add saturate() to backdrop-filter (minimum 1.3)
ALWAYS: Add inset highlight (inset 0 1px 0 rgba(255,255,255,0.03)) on glass surfaces
NEVER: Background alpha below 0.40 (readability) or above 0.70 (glass not visible)
NEVER: Blur below 36px for main surfaces (28px minimum for small elements)
NEVER: Tinted/colored glass backgrounds — always gray rgba values

25. Anti-patterns

What we NEVER do in Noir. These rules protect the monochrome audiophile identity.

Colors

NEVER: Colored gradients (blue-violet, rainbow, gold, etc.)
NEVER: Color accents other than white, green (playing), red (errors)
NEVER: Colored badge backgrounds (except green for playing state)
NEVER: Gold accent (#C9A962) — this was removed in v1.0.0
NEVER: Colored shadows (box-shadow with blue, green, etc.) except green glow for --color-green

Layout

NEVER: 3-column symmetric grids with icons in colored circles
NEVER: Hero sections with full-screen images and overlay
NEVER: Automatic carousels
NEVER: Emoji in titles or buttons

Typography

NEVER: Fonts other than Geist Mono and DM Sans (no Inter, no JetBrains Mono)
NEVER: Centered text (except fullscreen player)
NEVER: Positive letter-spacing on lowercase text (only on uppercase labels)

Effects

NEVER: Decorative blobs, floating circles, or wavy SVGs
NEVER: transition: all
NEVER: Animating width, height, top, left (use transform/opacity)
NEVER: border-radius > 12px on non-circular elements

UX

NEVER: Empty state with just text ("No items") — always message + primary action
NEVER: Generic buttons ("Submit", "Continue") — always specific verbs
NEVER: Confirmation modals without cancel option
NEVER: Loading without feedback (use shimmer/skeleton)

27. New Component Checklist

Before merging any new CSS component, verify every item below.

  • Uses only CSS tokens (--color-*, --sp-*, --fs-*, --radius-*, --shadow-*, --transition-*)
  • No direct hex/rgb color values (except in rgba() for glass/overlay)
  • No direct font-family — uses var(--font-body) or var(--font-sans)
  • No transition: all
  • No animation on width/height/top/left
  • :focus-visible state present on interactive elements
  • Touch target >= 44px (controls) or >= 28px (secondary actions)
  • Hover state defined
  • Active/pressed state: scale(0.92-0.97)
  • Works with prefers-reduced-motion: reduce
  • Glass morphism follows section 7 parameters
  • Glass borders use rgba(255,255,255,0.04-0.10)
  • backdrop-filter doubled with -webkit-backdrop-filter
  • Numbers use font-variant-numeric: tabular-nums
